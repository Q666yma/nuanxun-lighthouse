# 源码整理与验证说明

## 本包来源与整理范围

本包整合现有 Java 工程和当前部署使用的修改源码、Mapper、前端静态资源、服务端模板、Python 服务和数据库结构脚本。Java 工程共 141 个主程序源文件，完整保留当前角色权限、任务资料、联系人、地图和管理功能。

为便于在其他电脑解压运行，打包副本将固定上传目录改为可配置目录；遗留工具的固定发件邮箱、地图 Key 和 JWT 示例密钥改为配置项。注册资料提示使用化名。没有重新设计界面，也没有修改线上数据。

## 验证方式

1. 使用 JDK 11 对整个 Java 主程序源码编译，开启 UTF-8、Java 11 目标兼容和 `-parameters`，使用包内第三方依赖。
2. 检查 Python 服务及启动工具的语法；通过 Flask 测试客户端检查健康接口和未登录访问限制，不调用外部识别或邮件服务。
3. 检查打包目录中的配置与已知私人姓名；排除密钥文件、生产账号密码、实名对照、数据库备份、日志及私人上传资料。
4. 比赛压缩包生成后读取 ZIP 目录并做完整性检查；GitHub 版本另外排除离线 JAR、课程视频、编译输出和运行缓存，保留源码、前端资源和 SQL。

上述编译与 Flask 检查针对比赛整理源码完成，原始检查报告保留在本地比赛资料中。本仓库没有在另一套新 MySQL 环境中执行完整业务验收；复现者应按根目录 README 完成数据库初始化和外部服务配置，再验证发布、接单、反馈和确认流程。
