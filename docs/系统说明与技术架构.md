# 系统说明与技术架构

## 作品用途

暖寻灯塔是面向走失人员寻找与公益救援的 Web 协同平台。系统围绕发布求助、参与搜救、线索反馈和家属确认组织业务，并提供角色权限、站内通知、培训内容、心理关怀和数据可视化。

## 三类角色

| 角色 | 主要功能与数据范围 |
|---|---|
| 家属 | 发布和管理自己的求助，填写本次求助联系人及关系，查看任务进展、参与者和消息；使用获准展示的搜救概览、心理关怀、课程及感谢墙 |
| 搜救志愿者 | 申请与维护搜救资料；通过审核后接单，参与任务内地图标注、线索交流、位置共享、轨迹查看和辅助识别；查看培训与通知 |
| 管理员 | 用户和队员审核管理、任务协调、通知与加急处理、内容审核、统计及操作记录 |

待审核队员不能执行正式搜救操作。任务联系人、照片、语音和任务消息根据身份、任务归属及参与关系控制访问。不同角色的首页和菜单随权限显示，前端菜单不替代服务端校验。

## 数据流与程序分工

```text
浏览器（HTML / CSS / JavaScript / Layui / ECharts / 高德地图）
                         |
                    Nginx 同源入口
                         |
        +----------------+------------------+
        |                                   |
Java / Spring Boot / MyBatis        Python / Flask 智能辅助
账号、会话、权限、任务、联系人        技能信息、推荐、报告、海报
消息、地图数据、内容与后台管理        心理关怀、热力标注语义处理
        |                                   |
        +------------- MySQL ---------------+
        |
Redis：验证码等辅助状态

第三方能力：高德地图 / 智谱 / 百度人脸 / 讯飞声纹 / SMTP
```

Python 业务请求沿用 Java 会话验证；需要任务权限的操作再向 Java 核验具体任务。Nginx 同源转发保留会话 Cookie，私有上传资源由 Java 做授权控制。

## 主要源码位置

- Java 控制器：`java-backend/src/main/java/com/maka/controller`。
- 角色及任务授权：`support/RoleAccess.java`、`support/TaskAccess.java`。
- 求助联系人：`service/impl/TaskFamilyContactService.java`。
- 任务业务事务：`service/impl/FeatureTaskService.java`。
- 位置与轨迹：`controller/TaskLocationController.java`、`service/impl/TaskLocationService.java`。
- 热力渲染：`src/main/resources/static/js/task-heat-renderer.js`；Python 对应 `api/map_router.py` 及其服务实现。
- Python 权限桥接：`python-service/utils/authorization.py`。
- 数据库结构：`database/01-schema.sql` 至 `08-task-family-contacts.sql`。

## 运行与能力边界

基础账号和任务功能以自行搭建的 MySQL、Redis 及 Java 服务为基础。地图、邮件与 AI 能力还依赖外部配置及账号授权，不能把代码已集成等同于外部服务永久可用。声纹服务需在供应商账号中开通相应能力。

热力结果用于呈现标注语义或记录密度；不是走失风险、找到概率或安全结论。自动定位和共享位置由用户主动触发。新空库中的演示账号与演示资料不代表真实人员或真实警情。
